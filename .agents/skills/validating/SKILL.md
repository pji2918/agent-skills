# 작성/수정 후 검증

파일 작업을 마치면 사용자에게 보고하기 전에 아래 순서로 검증함.
작업 도중에는 돌리지 않음. 중간 상태에서는 불필요한 오류만 나오기 때문임.

## 1. 서식 통일

```bash
pnpx prettier . --write
```

- 저장소 루트에서 실행함.
  제외 대상은 `.prettierignore`가 정하므로 `.`로 돌려도 됨.
- 이 명령은 이번에 건드리지 않은 파일도 바꿀 수 있음.
  실행 뒤 `git status`로 바뀐 파일을 확인하고, 범위 밖 파일이 바뀌었으면 사용자에게 알림.

## 참고

- 터미널 명령 실행은 `terminal-exec` 스킬이 활성이면 그 규정대로 서브에이전트에 위임함.
  prettier의 `--write`는 포맷터 자동수정이라 허용되는 범위임.
