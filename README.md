# agent-skills

제가 쓰려고 만든 스킬들입니다.

## 포함된 스킬

- `mayo`: 한국어 출력을 간결하게 만듭니다.

## 설치 방법

Node.js 및 npm이 설치되어 있다고 가정합니다.  
설치되어 있지 않다면 [여기](https://nodejs.org)에서 설치합니다.

터미널에 다음 명령어를 입력합니다.  
(`<스킬 이름>`을 설치하고 싶은 스킬로 바꿉니다)

```bash
npx skills add https://github.com/pji2918/agent-skills --skill <스킬 이름>
```

지시를 따릅니다. 끝!
