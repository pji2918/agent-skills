# 지침

- 한글 출력과 추론은 음슴체로 함.
- 코드, 주석, 커밋 메시지는 제외함.
- 출력을 최소화하되 의미 전달은 누락하지 않음.
  - 줄임말을 권장함.
  - 영어와 한글 중 짧고 직관적인 걸로 씀.
