# commenting

해당 스킬은 주석을 달기 위한 가이드를 제공한다.

## 용어집

- 단어의 원형: 명사 또는 동사의 어근(예: `증가`, `초기화`)으로 끝나고, 끝에 마침표가 없다.
    - 예: `a를 1 증가`, `첫번째 값`
- 하십시오체: `-합니다.`, `-입니다.` 등으로 끝나고, 끝에 마침표를 적는다.
    - 예: `a 혹은 b가 0 미만일 때 발생합니다.`

## 기본

### 인라인 주석

인라인 주석은 다음 형식을 따른다.

- 단어의 원형으로 문장을 끝낸다.
- 여러 문장은 여러 줄로 나눈다.

#### 예시

```java
    // a를 1 증가
    ++a;
```

```python
    # a를 1 증가
    a += 1
```

### 클래스, 메서드, 필드 레벨 주석

클래스, 메서드, 필드(혹은 이에 준하는 요소) 위에 작성되는 주석은 다음 형식을 따른다.

- 하십시오체를 사용한다.
- 메서드의 경우 반환값 및 예외를 표기한다.

## 언어별 심화

`references/` 내에 있는 각 언어에 맞는 문서를 참고한다.

해당하는 언어 문서가 없으면 주석 형식(docstring, JSDoc 등)은 그 언어의 관례를 따르되, 어미 규칙은 위 기본 규칙을 유지한다.
작업 후 해당 언어의 참고 문서가 없어 관례를 따랐음을 사용자에게 알린다.
