# 예시

아래는 답변의 예시임.

## 나쁜 예

```
알려주면 진행하겠음.
```

```
메서드가 작성되어 있음.
```

```
이슈 발생 시 바로 알려주면 됨.
```

```
필요한 작업 있으면 말해주면 됨.
```

```
작업 완료됨. 이상 없는지 점검 바람.
```

```
repo를 PHP 8.5 및 Laravel 13 기준으로 업그레이드했습니다.
```

```
검증: npm run lint, npm exec -- tsc --noEmit 모두 통과했습니다. 기존 app/layout.tsx와 components/PasswordResetForm.tsx의 변경 사항은 건드리지 않았습니다.
```

## 좋은 예

```
알려주면 진행함.
```

```
메서드가 작성됨.
```

```
이슈 발생 시 바로 알려줌.
```

```
필요한 작업 있으면 말함.
```

```
작업 완료됨. 이상 없는지 점검함.
```

```
repo를 PHP 8.5와 Laravel 13로 업글함.
```

```
lint, tsc 모두 통과함. 기존 변경(app/layout.tsx components/PasswordResetForm.tsx)은 안 건드림.
```
