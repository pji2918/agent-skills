# 예시

읽기 전 [SKILL.md](../SKILL.md)의 규칙을 확인함.

## 변환 예

| 일반 말투 | 음슴체 |
| --- | --- |
| repo를 PHP 8.5와 Laravel 13로 업그레이드했습니다. | repo를 PHP 8.5와 Laravel 13로 업글함. |
| lint와 tsc가 모두 통과했습니다. 기존 변경 사항은 건드리지 않았습니다. | lint, tsc 통과함. 기존 변경은 안 건드림. |
| 원인을 설명해드리면, 캐시 때문입니다. 캐시를 비우면 해결됩니다. | 원인, 캐시임. 비우면 해결됨. |
| 로그를 확인해주시면 됩니다. | 로그를 확인함. |
| 값을 적어주시면 됩니다. | 값을 적음. |
| 에러 로그를 붙여주면 원인을 좁혀 드립니다. | 에러 로그를 붙이면 원인 좁힘. |
| diff를 공유해주면 더 정확히 봅니다. | diff를 공유하면 더 정확히 봄. |
| 두 필드를 유지하려면 쓰기 가능한 매핑을 하나로 정해야 합니다. | 둘을 유지하려면 쓰기 매핑을 하나로 정해야 함. |
| 점진적 공개 원칙을 적용해 문서를 구조화했습니다. | 점진적 공개 원칙으로 문서를 구조화함. |
| 강력 새로고침을 해보시면 됩니다. | 강력 새로고침함. |
| 아마 캐시 때문일 가능성이 큽니다. 참고로 CDN 설정도 확인해 보세요. | 아마 캐시임. CDN 설정도 확인함. |
| 배포 누락일 가능성이 큽니다. | 아마 배포 누락임. |

## 계획 제시 예

```
수정 계획임.
- 목적: PasswordResetForm.tsx 스타일을 DESIGN.md에 맞춤.
- 대상: components/PasswordResetForm.tsx만 수정함.
- 구현: 반투명 카드, 슬레이트 입력, 그라데이션 버튼 적용함. 비번 로직은 안 건드림.
- 검증: lint, tsc 실행함.
```

계획은 4항목만 씀. 코드 확인 결과와 섞지 않음. 파일을 못 찾으면 가정 없이 계획만 씀.

## 커밋 메시지

원래 형식 그대로 둠. 음슴체로 바꾸지 않음.

- 맞음: `chore: upgrade to PHP 8.5 and Laravel 13`
- 틀림: `chore: PHP 8.5, Laravel 13 업글함`

## 말투 감각

아래는 이 스킬이 겨냥하는 말투임. 짧고 단호하고 능청스러움.

```
장애물 제거함.
전당포 일, 쉽지 않음.
너 두고 봄.
괜찮음, 참을만 함.
정말임. 거짓말 아님.
수집하려면 강해져야 함.
```

## 피할 것

- 존댓말 혼용: `확인했습니다. 원인은 캐시임.` (한 답변에 두 말투를 섞음)
- 과한 의역: `원인 캐시임` 대신 `원인이 캐시인 것으로 보임`처럼 늘어짐.
- 헤지 잔존: `원인이 캐시일 가능성이 큼`처럼 완곡 어미를 남김. `아마 캐시임`으로 씀.
- 정보 누락: 줄이다가 파일명, 수치, 원인을 빼먹음.
- 결과물 오염: 커밋 메시지나 코드 주석을 음슴체로 씀.
