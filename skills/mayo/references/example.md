# 예시

아래는 답변의 예시임.

## 나쁜 예

```
알려주면 진행하겠음.
```

```
메서드가 작성되어 있음.
```

```
이슈 발생 시 바로 알려주면 됨.
```

```
필요한 작업 있으면 말해주면 됨.
```

```
작업 완료됨. 이상 없는지 점검 바람.
```

```
repo를 PHP 8.5 및 Laravel 13 기준으로 업그레이드했습니다.
```

```
검증: npm run lint, npm exec -- tsc --noEmit 모두 통과했습니다. 기존 app/layout.tsx와 components/PasswordResetForm.tsx의 변경 사항은 건드리지 않았습니다.
```

```
수정 계획입니다.
- 목적: PasswordResetForm.tsx의 시각 스타일을 DESIGN.md에 정리된 계정 폼 디자인 시스템에 맞춥니다.
- 대상 파일: components/PasswordResetForm.tsx만 수정합니다.
- 구현: 흰색 반투명 카드, 슬레이트 입력 필드, 라벨과 간격, 인디고-바이올렛 그라데이션 버튼, Pretendard에 어울리는 제목 스타일을 적용합니다. 비밀번호 제출·오류 처리 로직은 변경하지 않습니다.
- 검증: 관련 Next.js 문서를 확인한 뒤 npm run lint와 npm exec -- tsc --noEmit을 실행합니다.
```

```
두 필드를 유지하려면 쓰기 가능한 매핑을 하나로 정해야 합니다. 이 구조에서는 employeeId의 복합 연관관계를 쓰기 기준으로 삼고, companyId는 조회용으로 두는 방안이 적절합니다.
```

```
/reset-pw/success의 두 완료 상태에 디자인 시스템을 적용했습니다. 카드에 밝은 모드와 다크 모드 스타일을 넣고, 제목과 안내 문구의 위계를 정리했으며, 비밀번호 재설정 완료 화면의 로그인 버튼을 인디고-바이올렛 기본 버튼으로 바꿨습니다. 기존 문구와 링크 동작은 유지했습니다.
```
