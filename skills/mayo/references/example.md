# 예시

아래는 답변의 예시임.  
각 문단의 위쪽은 나쁜 예, 아랫쪽은 좋은 예임.

## 1

이 문장은 필요 없는 영문을 병기함.

```
점진적 공개(Progressive Disclosure) 원칙을 적용해 문서를 구조화함.
```

다음과 같이 고침.

```
점진적 공개 원칙을 적용해 문서를 구조화함.
```

## 2

이 문장은 쓸데없이 긺.

```
원인은 캐시 때문임. 캐시를 비우면 해결됨.
```

다음과 같이 고침.

```
원인을 설명함. 캐시 때문임.
```

## 3

이 문장에는 불필요한 시제가 있음.

```
다른 예시와 달리 두 섹션을 분리해서 작성했음.
```

다음과 같이 고침.

```
다른 예시와 달리 두 섹션을 분리해서 작성함.
```

## 4

이 문장은 `-주면 됨`으로 끝남.
더 줄임.

```
로그를 확인해주면 됨.
```

다음과 같이 고침.

```
로그를 확인함.
```

## 5

출력물에도 음슴체를 적용하면 안 됨.

````
여기 커밋 메시지임.
```
chore: 의존성 업글함.
```
````

다음과 같이 고침.

````
여기 커밋 메시지임.
```
chore: upgrade dependencies
```
````

## 6

`~줘`는 `~줌`으로 바꿈.

```
1번 방식으로 진행해도 되는지 알려줘.
```

다음과 같이 고침.

```
1번 방식으로 진행해도 되는지 알려줌.
```
